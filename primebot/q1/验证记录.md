# Q1 status 验证记录

2026-11-20 在启元 Q1 探索版、Apple 芯片 Mac 和本地 Motus Core 上验证。测试镜像使用本地 ARM64 Core 基础镜像 `release.261118.56edda4` 构建；厂商消息包在 Ubuntu 22.04 / ROS 2 Humble 下用 colcon 编译。

## 真机与画布

Motus Core 的 MCP 在线检查发现 `primebot-q1-device-bundle`，卡片列表包含 `status`。启动卡片后，画布「查看数据流」使用的 WebSocket `/ws/bus/primebot_q1/status` 返回 `data/json` 帧。18:12:35 至 18:12:36（UTC+8）连续三帧的顶层字段均为 `battery`，样本状态为 `live`。

| 指标 | 末帧读数 |
| --- | --- |
| SOC、剩余容量 | 76%，3526 mAh |
| 电压、电流、输出功率 | 51.09 V，−0.18 A，9.196 W |
| 温度、完整循环次数 | 33.3 °C，1 次 |
| 累计充放电容量、厂商状态位 | 5 mAh，0（BMS 原始上报） |

Mac 有线侧通过固定 UDP 端口将机器人 DDS 流量送入 Docker；Core 与 driver 的画布端共用网络命名空间。测试包含容器重启与重新发现。[Mac 本地复现步骤](tests/mac/README.md)

## 隔离集成测试

`tests/test_status.py` 使用本地 BMS 发布者，分别在域 87、88 验证厂商接口、跨域输出、数值换算、无样本、停止输出、过期数据与重新启动。测试不需要连接机器人。在驱动仓库根目录运行：

```bash
docker run --rm --network none \
  -v "$PWD/primebot/q1/tests:/work/primebot/q1/tests:ro" \
  primebot-q1:local bash -ec 'source /opt/ros/humble/setup.bash && source /q1_ws/install/setup.bash && /usr/bin/python3 /work/primebot/q1/tests/test_status.py'
```

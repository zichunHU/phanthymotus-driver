# vision2pose 边界与验证事项

首版目标是用固定机位跟踪一名操作者，让宇树 G1 在原地实时跟随双臂和躯干动作。本机通过 Motus 画布和吊挂的 MuJoCo 模型验证。模型保留完整下半身，骨盆和下肢固定，11 个上半身关节参与物理步进，使用具有限位和力矩限制的位置执行器。［[本机运行](../README.md)］

## 动作范围与现场设备

| 待确认项 | 需要确定的内容 |
| --- | --- |
| 「上半身」的关节清单 | 本机覆盖双侧肩部三个轴、肘屈伸、腕滚转及腰部偏航。接入真机前按现场 G1 核对 11 个目标关节的轴向、零位、限位和反馈。 |
| 动作与验收范围 | 躯干以左右水平转动为首版验收动作。分别确定双臂、双腕、躯干与组合动作的允许幅度、速度和中立姿态。 |
| Driver 控制接口 | 本机发布带关节名、单位和源时间的目标，由 MuJoCo 消费。接入真机前核对 Driver 的双臂与腰轴控制入口、明确控制权的唯一持有者，并使用真实关节反馈完成暂停、停止和交权验收。［[G1 遥操与执行逻辑](../../../unitree/g1/motion/README.md)］ |

## 感知与动作映射

| 待确认项 | 需要确定的内容 |
| --- | --- |
| 相机与取景 | 确认相机来源、布置、视野和时延。示教画面需同时容纳两肩、两肘、双腕、双手和髋部参考点。确认镜像设置与解剖学左右的对应关系，并验证跟随过程中不会切换到画面中的其他人。 |
| 骨架数据与时效 | **3D Pose** 对同一 RGB 帧运行 MediaPipe 人体和手部模型。人体关键点用于判断骨架帧是否有效。手掌按图像腕点独立关联到左右手，缺失或匹配不明确的一侧保持当前腕滚转目标。Docker 接收到的相机话题时间戳用来判断帧龄，本机阈值为 0.55 秒。 |
| 三维信息与腕部滚转 | 腕部滚转取自前臂轴和掌面方向。躯干水平转动来自肩线相对髋线的旋转。实际角度精度受单目深度估计、相机视角和遮挡影响，应在现场机位分别验证转腕和转体方向。［[实时视觉模仿参考](https://www.techscience.com/cmc/v89n1/68392/html)］ |
| 人体到 G1 的映射 | 以示教者和 G1 的中立姿态标定相对运动。双侧臂段以躯干为参考，与腰偏航在同一观测上求解。本机关节目标变化率上限为每秒 1 弧度，真机参数依据实际设备重新核对。 |

## 启动、暂停与停止

- **启动**。画布连线后显示预览。标定需要有效的上半身骨架和双掌，以记录两侧腕滚转的参考姿态。标定后，由操作者启动跟随。
- **暂停**。上半身骨架缺失、主体不明或帧过期时，整段跟随暂停，停止发布新关节目标并记录原因。仅手掌缺失时，肩、肘、腰和仍可识别的一侧腕部继续跟随。缺失的一侧保持当前腕滚转目标，恢复识别后按关节速度限制续接。
- **续接**。同一示教者的有效骨架恢复后手动执行 `follow`。如果跟踪身份变化，重新执行 `calibrate`。切换视频、摄像头或机位时重新标定。
- **停止**。验证画布停止入口、驱动主动停止与实际控制权交还。验收同时观察目标流和实测反馈，分别记录停止发出目标、本体停止跟随及交权结果。
- **视频输入**。画布读取当前浏览器可解码的本地视频，以静音方式逐帧送入本机识别。暂停或播完时持续提供当前帧。切换来源需先停止智能控制，刷新后需重新选取视频。浏览器输入与命令行回放共用同一话题，每次只运行一种来源。
- **真机前提**。先完成双臂、躯干及组合动作的仿真和画布联调。真机阶段采用原地站立、低速和明确的工作范围，核对角度与变化率限制、双臂与躯干的可用空间以及相应停机手段。［[G1 遥操与执行逻辑](../../../unitree/g1/motion/README.md)］

## 验收用例与证据

| 用例 | 需要观察的结果 |
| --- | --- |
| 正常跟随 | 双臂同步抬举、左右不对称屈伸、双腕转动、左右转体及回到中立位。核对左右映射、动作方向、中间姿态和回正结果。 |
| 组合动作 | 转体同时抬臂。检查双臂与躯干目标是否同步，关节角和目标变化率是否符合约束。 |
| 跟踪异常 | 分别遮挡单侧和双侧手掌，核对受影响的腕滚转保持、其他关节继续跟随及手掌恢复后的自动续接。再遮挡手臂或髋部、让操作者离开或其他人入镜，测试断流与帧过期，核对整体暂停和手动续接。 |
| 终止执行 | 主动点击停止，核对运动目标、生效状态和本体反馈。 |
| 实时表现 | 用有时间对照的画面、目标数据和实测关节曲线记录跟随延迟与动作偏差。验收前确定测试动作、计时口径、可接受延迟、偏差与暂停响应时间。 |
